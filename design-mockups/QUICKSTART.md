# 🚀 دليل البدء السريع

## خطوة واحدة للمعاينة!

### افتح الملف التالي في المتصفح:

```
design-mockups/index.html
```

## أو استخدم الأوامر التالية:

### على Mac/Linux:
```bash
open design-mockups/index.html
```

### على Windows:
```bash
start design-mockups/index.html
```

### أو من Terminal:
```bash
cd design-mockups
python3 -m http.server 8000
# ثم افتح http://localhost:8000 في المتصفح
```

## 📱 الصفحات المتاحة

بعد فتح `index.html` ستجد روابط مباشرة لـ:

1. **الصفحة الرئيسية** - مع Timeline وقسم الأمان
2. **صفحة إنشاء الطلب** - مع Stepper والسعر المباشر
3. **صفحة تفاصيل الطلب** - مع العروض والمحادثة

## ✨ نصائح للمعاينة

- 📱 جرّب فتح المعاينات على الجوال للحصول على أفضل تجربة
- 🖱️ مرر الماوس على العناصر لرؤية Hover Effects
- 💬 في صفحة تفاصيل الطلب، اضغط على زر المحادثة لفتح Bottom Sheet
- 🔄 جرّب تغيير حجم النافذة لرؤية Responsive Design
